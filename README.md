# Codex 飞书侧栏

点击 Chrome 工具栏的 **Codex 飞书侧栏**。打开飞书文档，输入问题或明确说明需要的修改。单独粘贴飞书链接可以添加参考。按 **Enter** 发送，按 **Shift + Enter** 换行。

侧栏按网页记住会话。切到另一个网页时，可以在该网页发起独立任务，先前网页的任务继续执行。重新打开侧栏会尝试恢复该页的历史记录。后台执行依赖侧栏保持打开。同一 Chrome 配置中的侧栏共用一个本机 Codex 服务，各网页或工作区按会话分别接收回复。后台空闲会话暂停连接，切回来后恢复历史；草稿与参考链接保留。执行中、加载中或结果待确认时不会主动休眠连接。连接休眠不改变会话后台闲置 2 小时后回收的规则。

### 回收闲置会话

网页工作区菜单提供「回收闲置会话」，可立即释放后台空闲会话的页面和本机连接，历史记录与工作区配置保留，再打开该页会恢复历史。后台闲置 2 小时后会自动回收，不设按数量回收的上限。每分钟检查一次，也会在切换网页时检查。当前显示的会话、运行中的任务、有草稿或参考链接、正在加载和结果待确认的会话会保留。

### 网页工作区

展开输入框左下角的工作区菜单，输入名称并新建，可选择是否加入当前网页。在列表中点「加入此页」会加入并切换。也可以打开任意工作区的管理页，批量添加已打开的网页，保留当前会话。切换同组页面会打开同一个会话。同组页面都可按明确指令读写，Codex 可以按问题取用。

每个网页工作区会记住一个聚焦页。初次使用时选当前成员页；切换浏览器标签或重新打开侧栏，仍保留该页。点击输入框里的「聚焦页」选择组内另一页，才会切换默认目标。「修改这里」作用于聚焦页，明确指定组内其他页面或多个页面时也可执行对应修改。任务执行期间显示发送时锁定的目标页。聚焦页移出工作区后，会改用当前成员页，或组内第一份资料。单页会话仍按各自网页聚焦。

不同工作区有各自的顶栏颜色，输入框左下角的按钮显示工作区名称，旁边显示当前页或本轮目标页。打开工作区管理可以改名、打开成员页、移出成员或删除分组。删除工作区会保留网页和历史对话。一个网页加入多个工作区时，可以选用其中一个，或切回它自己的单页会话。工作区资料与会话设置保存在当前 Chrome 配置中，工作区仍可单独选择本机工作目录。

右上角 **⋯ → 工作目录** 菜单可以选用曾授权的文件夹，或通过 **选择或新建文件夹…** 打开 macOS 文件夹选择器。在选择器中用「新建文件夹」建好目录后，点「使用此文件夹」。同一网页在不同工作目录下分别保留会话。

**改名**会修改侧栏里的显示名称。**移除**会撤回侧栏对该目录的授权，文件夹和会话记录仍保留。默认目录可改显示名称，移除其他正在使用的目录后会切回默认目录。

点击右上角 **⋯ → 字体设置** 可以调整对话和输入框的字号与字形，默认字号为 16 px。设置保存在本机，下次打开会沿用。

侧栏随 Chrome 提供的浅色或深色偏好切换。对话和历史消息支持 Markdown 标题、列表、表格、引用和代码块。Markdown 图片显示为链接，点击后打开。

输入框底部可切换思考强度 **低 / 中 / 高**。默认中，选择只影响侧栏发出的请求，并在下次打开侧栏时保留。

发送后，输入框上方显示本轮进度和耗时。工具开始、工具返回、输出回复与执行结束的状态来自本机 Codex 事件。

启用按网页切换会话时，Chrome 会询问是否允许读取标签页信息，可能把这项权限显示为「读取您的浏览记录」。发送时会读取当前活动标签的地址。发给 Codex 的网页地址会移除登录信息和非必要参数。明确要求修改时，默认目标是发送时选定的聚焦页。工作区成员都可按用户指令读写。本机 Codex 以 `--as user` 身份读写该文档。连接器优先使用已安装的 `codex-lark-cli`，也支持普通安装的 `lark-cli`。单独粘贴的参考链接只供读取，加入工作区的页面可按明确指令修改。写入超时或连接中断时，请先查看飞书原文。

点击右上角 **⋯** 查看当前 Codex 账号下由侧栏发起的历史，选择标题即可打开并继续追问。长会话可点 **加载更早的消息**。如果长时间收不到新进度，侧栏会提供 **重新连接**，输入框中的草稿会保留。

## 安装或修复

从 Chrome 商店安装的版本将在侧栏引导你安装 Mac 连接器。打开下载的 `.pkg`，完成安装后返回侧栏检查连接。连接器适用于 macOS 13 及以上的 Apple Silicon Mac，直接查找本机 Codex。用户安装时无需 Python。曾在本机登录过 Codex 的用户可沿用现有登录，飞书 CLI 继续使用既有账号。

### 开发版连接器

在已安装 Codex 和 Python 3 的 macOS 上，从本目录运行 `python3 install.py`。连接器会查找终端中的 Codex，并尝试使用标准位置的 ChatGPT 应用自带的 Codex。也可以用 `--codex` 指定可执行文件，用 `--workspace` 指定希望使用的工作目录。

脚本将桥接安装到当前用户的 Library，并为扩展注册 Chrome 本机通信。开发版打开 `chrome://extensions`，启用开发者模式，点 **加载未打包的扩展程序** 并选择脚本打印的 `extension` 目录。使用商店版时由安装器传入正式的 `--extension-id`。

侧栏使用独立的本机 Codex 服务，沿用本机登录和工具配置。网页工作区由扩展保存在当前 Chrome 配置中，本地工作目录用于 Codex 文件操作。桌面端的项目组织和侧栏的网页工作区分别管理。

侧栏分别显示 Codex 的连接状态和独立飞书 CLI 的检测结果。Codex 已登录就沿用现有登录。飞书 CLI 为可选依赖。已配置的用户可沿用原有账号，在飞书文档打开侧栏时，Mac 连接器会使用现有飞书 CLI 用户身份自动只读检查当前浏览器标签页里的飞书文档，结果显示在顶部。失败时可复制报错和修复指令到 Codex。旧会话缺少文档工具时，可从侧栏新建会话，旧会话仍可通过历史打开。

修改侧栏代码后到 Chrome 的扩展管理页点重新加载。修改本机桥接后重新运行安装脚本，关闭并重新打开侧栏。移除扩展时，可一同移除 `~/Library/Application Support/Google/Chrome/NativeMessagingHosts/local.codex_sidepanel.json` 和 `~/Library/Application Support/Codex Feishu Sidepanel`。

### 构建 Mac 安装包和商店 ZIP

发布者在装有 macOS Command Line Tools 和 Python 3 的 Mac 上运行 `python3 macos/build-release.py --extension-id <扩展ID>`。不传下载地址时，输出本地测试安装包和配套扩展源码 ZIP。解压后可用 Chrome 的「加载未打包的扩展程序」安装配套扩展。

正式发行时，在 Chrome 商店开发者后台取得正式扩展 ID。构建时设置 `CONNECTOR_APP_SIGN_ID` 和 `CONNECTOR_INSTALLER_SIGN_ID`，分别对应 Developer ID Application 与 Developer ID Installer 签名身份，并通过 `--download-url` 指定安装包的 HTTPS 下载地址。安装包经过 Apple 公证及装订公证凭证后再上传到该地址。商店 ZIP 含对应的下载按钮和首次连接前的数据用途说明。测试包用于本地验收。

## 稳定性验证

运行 `node --test tests/*.cjs` 验证重连竞态、断线状态释放、旧目录和历史响应隔离、请求超时、历史分页异常、执行目标锁定及后台回复完成。请求不会因超时或重连自动重发；结果不明时应先查看历史并核对原文。

### 添加附件

使用 2.3.9 Mac 连接器时，可通过输入框下方的「＋」打开 macOS 选择器，引用原位置的图片、文件和文件夹。每条消息最多添加 5 项。选取的文件和文件夹无需传给浏览器，也无需复制到缓存。文件移动、删除或连接器重启后，尚未发送的引用需要重新选择。直接粘贴截图仍通过连接器传输，合计上限为 8 MB。附件交给已配置的 Codex 模型服务处理。

使用 `macos/build-release.py` 构建 Mac 测试版。安装生成的 `.pkg` 连接器，再在 Chrome 加载测试版 ZIP 解压后的目录。

### 手动归档会话

在侧栏「会话与设置」中，点击对应会话右侧的「归档」。可从「已归档」查看并恢复会话。归档状态与 Codex 同步，运行中的会话结束后可以归档。
