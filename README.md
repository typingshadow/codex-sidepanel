# Codex 飞书侧栏

在 Chrome 侧栏里使用本机 Codex。打开飞书文档后，可以直接提问、整理内容，或明确说明要修改哪一段。

## 1. 如何安装

1. **准备环境。** 在 Mac 上安装 Chrome、Python 3 和 Codex。本机的 Codex CLI 或安装在「应用程序」里的 ChatGPT 自带 Codex 都可以。先登录 Codex，侧栏会沿用本机登录。
2. **下载源码。** 在本仓库点 **Code → Download ZIP**，解压到一个固定位置。也可以用 Git 克隆。
3. **安装本机连接器。** 在终端进入包含 `install.py` 的目录，运行：

   ```bash
   python3 install.py
   ```

   安装成功后，终端会打印扩展目录。如果提示找不到 Codex，可用 `python3 install.py --codex "/你的路径/codex"` 指定可执行文件。
4. **加载 Chrome 扩展。** 在 Chrome 打开 `chrome://extensions`，开启「开发者模式」，点「加载未打包的扩展程序」，选择上一步打印的 `extension` 目录。
5. **检查连接。** 点击 Chrome 工具栏里的「Codex 飞书侧栏」。如果找不到图标，从工具栏的「扩展程序」菜单打开。确认侧栏已连接本机 Codex。需要读写飞书文档时，还要在本机安装并授权飞书 CLI。连接器优先使用 `codex-lark-cli`，也支持 `lark-cli`，读写时使用已授权的飞书用户身份。

更新源码后，在 Chrome 扩展管理页点「重新加载」。如果更新了本机连接器，再运行一次 `python3 install.py`，然后关闭并重新打开侧栏。

如果看到「本机连接器不支持飞书读取检查」，请更新源码，再运行一次 `python3 install.py`。扩展和连接器分别安装，重新加载扩展后仍需更新连接器。

### 使用配套 Mac 测试包

在 Apple Silicon Mac（macOS 13 或更新版本）上，先安装 `Codex-Browser-Connector-版本号.pkg`，再解压同版本的 `Codex-Sidepanel-Mac-Test-版本号.zip`。首次安装时，在 Chrome 扩展管理页加载解压后的目录。已有扩展时，用 ZIP 里的文件更新当前加载的扩展目录，再点「重新加载」，以保留本地会话设置。测试包里的扩展会连接配套的 Mac 连接器。

## 2. 如何使用

### 在飞书文档旁提问或修改

1. 打开一份飞书文档，再打开侧栏。侧栏顶部会显示该文档的飞书 CLI 检测结果。首次启用按网页切换会话时，Chrome 可能会询问是否允许读取标签页信息，以便侧栏识别当前页。
2. 在输入框直接交代任务。比如「总结这篇文档的三项待办」，或「把当前文档第二段改得更简洁，保留原来的日期和数字」。
3. 按 **Enter** 发送，按 **Shift + Enter** 换行。任务进度显示在输入框上方。

把飞书链接单独粘贴到输入框，可以添加只读参考。要修改文档，请明确说明修改范围。写入时如果超时或断线，先查看飞书原文，确认是否已经写入，再决定是否重发。

### 管理会话和工作区

- **按网页继续对话。** 每个网页可以有独立会话。切换标签页后，先前的任务可在侧栏保持打开时继续执行。
- **把多份资料放在一个会话里。** 从输入框左下角新建「网页工作区」，把相关网页加入同一组。用「聚焦页」指定默认操作的页面。要修改组内其他页面时，在指令里点明目标。
- **查看历史或归档。** 点右上角 **⋯** 打开「会话与设置」，可以继续历史对话，也可以归档已结束的会话。已归档的会话可以恢复。
- **处理本机文件。** 在 **⋯ → 工作目录** 选择 Codex 要使用的本机文件夹。点输入框旁的 **＋** 可以附加图片、文件或文件夹，也可以直接粘贴截图。
